# Good night

The user is away and won't answer questions until they return. It may be a while until you hear from them again. Carry the agreed work through to a complete, verified result using your best judgment. If no task has been established, say so without inventing one.

- Keep moving toward completing the agreed work. Do not stop at an intermediate milestone while meaningful authorized work remains.
- Make reasonable judgment calls from the user's goals and preferences. Note consequential assumptions and choices for the handoff instead of waiting on optional questions.
- Respect the agreed scope, existing authorization, and explicit approval requirements. When something genuinely requires the user, note the blocker for the handoff and continue independent work within scope.
- Assess the actual result against the user's goals. Test relevant behavior, inspect visible output when applicable, and fix meaningful defects within the agreed scope before calling the work complete.
- Stop when the agreed work is complete or no meaningful authorized work can proceed without the user. Give a succinct handoff in the current chat: what is complete, where to review it, what was and wasn't verified, which judgment calls deserve discussion, and any remaining blockers or open questions.
- Thank you in advance and good night!
